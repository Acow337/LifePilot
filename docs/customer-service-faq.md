# 智能客服 FAQ

## 登录与账号

- 用户可以使用手机号和验证码登录。
- 如果验证码频繁发送失败，系统会触发临时限流，请稍后再试。
- 登录过期后需要重新登录，涉及订单、个人优惠券等信息时必须携带登录 token。

## 店铺与优惠券

- 用户可以按店铺 ID 查询店铺详情和可用优惠券。
- 普通优惠券展示标题、使用规则、支付金额和抵扣金额。
- 秒杀券会额外关注库存、开始时间和结束时间。
- 如果查不到店铺或优惠券，建议用户确认店铺 ID 或换一个店铺查看。

## 秒杀订单状态

- 秒杀下单成功提交后，订单会先进入排队处理状态。
- `PENDING` 表示正在排队，请稍后刷新。
- `SUCCESS` 表示下单成功，可继续查看订单状态。
- `FAIL` 表示下单失败，常见原因包括库存不足、重复下单、活动未开始或活动已结束。
- 如果订单状态长时间未更新，建议联系人工客服处理。

## 订单履约与退款

- LifePilot 的订单履约主线是：待支付 → 待核销 → 已核销，或待核销 → 退款中 → 已退款。
- 用户未支付前可以取消订单，取消后订单进入已关闭状态。
- 用户已支付但未核销前可以申请退款，申请后进入退款中，由运营后台审核。
- 管理员通过退款后订单进入已退款，拒绝退款后订单回到待核销。
- AI Agent 可以查询订单状态机时间线和解释退款规则，但不直接执行退款、支付、核销等写操作。

## 营销活动与库存

- Campaign 是 LifePilot 的统一营销活动模型，可承载普通券、秒杀券、新人券、会员券和满减活动。
- 活动规则包括时间窗、库存、用户限购、适用店铺、适用人群和预算上限。
- 秒杀活动会先通过 Redis Lua 完成资格校验，再通过 RabbitMQ 异步创建订单。
- 库存账本会记录预占、扣减、释放和回滚，用于解释库存变化和异常补偿。

## 探店笔记与评论

- 用户可以查看热门探店笔记和笔记详情。
- 登录后可以发布评论和回复评论。
- 删除评论通常需要本人或管理员权限。
- 内容应避免广告、辱骂、违法信息和与店铺无关的信息。

## 图片上传

- 探店图片建议使用 jpg、jpeg、png、webp 格式。
- 单张图片大小建议不超过 5MB。
- 如果上传失败，请检查图片格式、网络状态和登录状态。

## 人工客服

- 当用户涉及退款、投诉、敏感隐私、订单异常长期未恢复时，应建议转人工。
- 当前演示环境没有真实人工坐席，可提示用户保留订单号、手机号后四位和问题截图。

## 演示建议问题

- 我想看一下 1 号店铺有什么优惠券。
- 帮我查一下订单 123456789 的秒杀状态。
- 帮我看一下订单 123456789 现在履约到哪一步了。
- 退款中一般多久处理？AI 能直接帮我退款吗？
- 秒杀失败一般是什么原因？
- 图片上传失败怎么办？
- 我想联系人工客服。
